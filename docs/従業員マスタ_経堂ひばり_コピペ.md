# 従業員マスタ投入（経堂・ひばりが丘）

旧 `gas-kyodo` の `CONFIG.SHOPS`（店舗名 → 氏名表記ゆれ → バイバイ社員コード）を、新スプシの **従業員マスタ** に落としたものです。

## 理解（旧 → 新）

| 旧 | 新 |
|----|----|
| `SHOPS["経堂"][氏名]` | 従業員マスタ1行（`primary_store_id = S001`） |
| `SHOPS["ひばりが丘"][氏名]` | 同上（`S002`） |
| 氏名の全角/半角スペースゆれ | **正本は半角スペース1つ**（例: `日下 竜汰`）。`name_key` は空白除去 |
| 社員コード数値 / `"030396"` | `bye_code` 列。**先頭0は消さない**（貼る前に列を文字列にする） |
| 店舗名ハードコード | `店舗マスタ` の `store_id`（経堂=`S001` / ひばりが丘=`S002`） |

※ 旧コードは「シフト表の名前文字列 → コード」用の辞書。新アプリでは **1人1行** だけ置けば足りる（表記ゆれは全部並べない）。

## 貼る場所

シート **`従業員マスタ`**（ヘッダが1行目にある前提）。  
**2行目以降**に下のタブ区切りを貼る。サンプル行（E001 日下…）が残っていれば先に消すか上書き。

### 事前チェック

1. **店舗マスタ** に次があること  

```
S001	経堂	第7エリア	TRUE	10	
S002	ひばりが丘	第7エリア	TRUE	20	
```

2. `bye_code` 列（E列）を選択 → 表示形式 → **書式なしテキスト**（`030396` が `30396` にならないように）

## 規則（コピペ時）

| 列 | 規則 |
|----|------|
| employee_id | 一意。一度決めたら変えない（`EK…`=経堂 / `EH…`=ひばり） |
| name | 姓と名のあいだは **半角スペース** |
| name_key | name から空白を全部消したもの |
| email | 分かっている人だけ。空欄可（カレンダー同期時に後で埋める） |
| bye_code | バイバイの社員コード（文字列） |
| primary_store_id | 主所属店舗ID（`S001` / `S002`）。店舗名は入れない |
| employment_type | `社員` / `パート` / `その他`（黒川のみ旧設定でパート想定） |
| is_active | `TRUE` |
| calendar_sync | メールがある人は `TRUE`、無い人は当面 `FALSE` |
| memo_offset | 旧カレンダー互換。中田のみ `2`、他は `1` |
| note | 任意 |

## まだ空欄・後で直すもの

- **メール**: 石田・行徳・澤野・齊木・ひばり全員（カレンダー同期する人だけ埋める）
- **employment_type**: 社員/パートが違う場合はスプシで修正
- Webの「従業員登録」からも同じ列に書けます。スプシ直打ちと併用可（`employee_id` / `bye_code` の重複に注意）
