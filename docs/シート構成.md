# シート構成たたき台

対象スプシ: [新 シフト『キンタイ・カレンダー』管理](https://docs.google.com/spreadsheets/d/1mPb5xUeoDoT5--yEXqUw5bY0PBpQ2AWSo17zkWML4ww/edit)

## 方針

- スプシは **DXチーム専用のデータ置き場**（一般従業員にはURLを渡さない）
- 現場は **Webアプリ1URL** のみ。店舗を選ぶとその店舗分だけ表示・編集
- 裏のデータは「表計算の見た目」ではなく、**1行＝1事実** の正規化表にする
- 旧 `gas-kyodo` のカレンダー同期・バイバイ貼り付けは、後からこの表を読んで自動化する想定

---

## シート一覧（初期）

| シート名 | 役割 | 誰が触る |
|----------|------|----------|
| 店舗マスタ | 全店の一覧・表示順・有効フラグ | DXのみ（Web経由も可） |
| 従業員マスタ | 氏名・メール・勤怠コード・所属店舗 | DX／本人入力（Web） |
| シフト | 日ごとの勤務・休み・勤務地 | 現場はWebのみ |

| 権限 | 誰がどの店舗を見られるか | DXのみ |
| 設定 | アプリ用の定数 | DXのみ |
| 同期ログ | カレンダー／勤怠出力の履歴 | システム自動 |

`シート1` は不要になったら削除してよいです。

## 3. シフト（中核）

**1行 = ある人の、ある日の、ある店舗での予定**

| 列 | 名前 | 例 | 説明 |
|----|------|-----|------|
| A | shift_id | SH20260805-E001 | 一意ID（GAS/Webが採番） |
| B | date | 2026-08-05 | 日付 |
| C | employee_id | E001 | 従業員マスタ参照 |
| D | store_id | S001 | その日の勤務店舗 |
| E | status | work / off / pto / absent / undef | 勤務 / 公休など / 有休 / 欠勤 / 未定 |
| F | start_time | 12:00 | status=work のとき必須 |
| G | end_time | 21:00 | 同上 |
| H | break_minutes | 60 | 任意。勤怠出力用 |
| I | source | web / import / system | どこから入ったか |
| J | updated_at | 2026-08-05 16:00:00 | |
| K | updated_by | email | 最終更新者 |

### status の意味（カレンダー連携の目安）

| status | 画面 | カレンダー（既存gas-kyodoの思想） |
|--------|------|-----------------------------------|
| work | 勤務 12:00–21:00 | 勤務場所: 店舗名（棒線）／勤務帯は空き扱い |
| off | 公休など | 不在（outOfOffice） |
| pto | 有休 | 不在 |
| absent | 欠勤 | 不在 |
| undef | 未定 | 未反映 or 警告 |

## 5. 権限

Webで「店舗名を入れたらその店だけ」を安全にするための表。

| 列 | 名前 | 例 | 説明 |
|----|------|-----|------|
| A | email | store-mgr@... | Googleログインメール |
| B | store_id | S001 | 見られる店舗 |
| C | role | viewer / editor / admin | 閲覧 / 編集 / DX相当 |
| D | is_active | TRUE | |

- **admin**: 全店（store_id 空、または特別値 `*`）
- **editor**: 担当店のシフト・メモ編集
- **viewer**: 閲覧のみ

店舗名の手入力だけだと他店も見えてしまうため、本番は **ログインメール × 権限** で候補店舗を出す想定。

## Webアプリとの対応（イメージ）

```
従業員 → Web URL（1つ）
        → Googleログイン
        → 権限シートから「自分の店舗」だけ選択可能
        → シフト / シフトメモ を読み書き
                ↓
        スプシ（DXのみ閲覧）
                ↓
        GAS（後続）
          ・Googleカレンダー反映
          ・バイバイ貼り付け生成
          ・レイバー出力（必要なら）
```

TODOリスト（taskmaster-pro）と同じ型:

- 表はシート、触るのはWeb、処理はGAS
- 今回は「タスク」ではなく「シフト・勤怠・カレンダー」に特化

---

## 旧シフト表（行列型）との関係

現行 `gas-kyodo` は「スタッフ行 × 日付列」のシートを読んでいます。  
新方式では **正規化表（シフト）を正** とし、必要ならGASが:

1. 正規化表 → カレンダー  
2. 正規化表 → バイバイ貼り付け  
3. （移行期間のみ）旧行列シート ↔ 正規化表の変換  

とします。最初から全店を行列シートで増やさない方が、壊れにくいです。
