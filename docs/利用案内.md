## 【アプリ】（アルバイト）

**SHIFT:ONE**

▼ インストール  
https://shift-one-staff.vercel.app

1. スマホで上のリンクを開く
2. インストール → ホーム画面に追加
3. **ホーム画面の SHIFT:ONE アイコン** から開く
4. 初回：社員コード・氏名・パスワードで登録（メール不要）
5. 2回目以降：社員コード ＋ パスワードでログイン
6. 勤務の確認・希望申請・店舗チャットが使えます

※ ブラウザのタブではなく、**必ずアイコンから** 開いてください
