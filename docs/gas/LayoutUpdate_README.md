# LayoutUpdate.gs — レイアウト更新専用（データ保持）

既存データがあるスプシ向けです。**中身は消しません。**

## 入れるファイル

Apps Script に **別ファイル** として追加:

| GAS上の名前 | リポジトリ |
|-------------|------------|
| `LayoutUpdate` | [`LayoutUpdate.gs`](./LayoutUpdate.gs) |

`SetupSheets` / `Code` / `index` はそのまま残してOKです。

## メニュー（シフト基盤）

| メニュー | 内容 |
|----------|------|
| **不足シートを追加（データ保持）** | `週間固定` などが無ければ作る。既存シートは触らない |
| **レイアウト再適用（データ保持）** | 色・列幅・フィルタ・入力規則だけ直す |
| **従業員マスタに店舗フィルタを付ける** | 本体にフィルタ＋「従業員_店舗別ビュー」を作成 |

## 店舗で絞って見る方法

1. メニューで **従業員マスタに店舗フィルタを付ける** を実行  
2. `従業員_店舗別ビュー` の **B1** で店舗名（例: 経堂）を選ぶ  
3. その店の従業員だけ下に表示される  

正本の編集はいつも **`従業員マスタ`**（`primary_store_id` = `S001` など）。  
`店舗ID早見` シートで store_id と店舗名の対応を確認できます。

## 相互編集について

- Webアプリもスプレッドシートも **同じシート** を読み書きします  
- 口頭で「ここ直して」と言われたら、管理者はスプシから直接直してOK  
- Webを開き直す／再表示すると反映されます  

## 注意

- **初期セットアップ（全消し）** は `SetupSheets.gs` 側です。データがある本稼働後は使わない  
- レイアウトを変えたいときは、この `LayoutUpdate.gs` を差し替えてメニュー実行
