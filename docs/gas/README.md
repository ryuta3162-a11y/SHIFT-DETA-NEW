# SetupSheets.gs — 貼り付け手順

対象スプシ: [新 シフト『キンタイ・カレンダー』管理](https://docs.google.com/spreadsheets/d/1mPb5xUeoDoT5--yEXqUw5bY0PBpQ2AWSo17zkWML4ww/edit)

## 手順

1. 上記スプレッドシートを開く  
2. **拡張機能 → Apps Script**  
3. 既定の `コード.gs` を開き、中身を全部消す  
4. [`SetupSheets.gs`](./SetupSheets.gs) の内容を **すべてコピーして貼り付け** → 保存  
5. スプレッドシートのタブを再読み込み  
6. メニュー **「シフト基盤」→「シート構成を初期セットアップ」** → 「はい」

## できること

- `使い方` ＋ マスタ／シフト／権限／設定／同期ログ を一括作成  
- ヘッダ固定・色分け・列幅・フィルタ・入力規則（チェックボックス／リスト）  
- 試験用サンプル（経堂・ひばりが丘、権限 admin）  
- 「レイアウトだけ再適用」でデータは残したまま見た目と規則だけ再設定  

## 注意

- 初期セットアップは **同名シートを消して作り直します**（確認ダイアログあり）  
- この GAS は **このブック専用**。`taskmaster-pro` や `gas-kyodo` には入れない  
- スプシの共有は DXチームのみのままにする
