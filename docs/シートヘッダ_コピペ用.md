# シートヘッダ（1行目に貼り付け用）

各シートの **A1** に貼ってください。タブ区切りなので、セルにそのまま分かれます。

## 店舗マスタ

```
store_id	store_name	area	is_active	sort_order	note
```

## 従業員マスタ

```
employee_id	name	name_key	email	bye_code	primary_store_id	employment_type	is_active	calendar_sync	memo_offset	note
```

## シフト

```
shift_id	date	employee_id	store_id	status	start_time	end_time	break_minutes	source	updated_at	updated_by
```

## シフトメモ

```
memo_id	date	employee_id	store_id	kind	title	start_time	end_time	body	updated_at	updated_by
```

## 権限

```
email	store_id	role	is_active
```

## 設定

```
key	value	note
```

## 同期ログ

```
logged_at	type	target	range	result	message
```
