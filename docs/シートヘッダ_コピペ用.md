# シートヘッダ（1行目に貼り付け用）

各シートの **A1** に貼ってください。タブ区切りなので、セルにそのまま分かれます。

## マスターデータ

```
店舗ID	店舗名	エリア	社員コード	氏名	メール	雇用区分	勤務時間
```

## シフト

```
シフトID	日付	従業員ID	店舗ID	区分	開始	終了	休憩分	入力元	更新日時	更新者
```

## シフトメモ

```
メモID	日付	従業員ID	店舗ID	種類	件名	開始	終了	内容	更新日時	更新者
```

## 週間固定

```
週間ID	従業員ID	店舗ID	曜日	区分	開始	終了	休憩分	有効	更新日時	更新者
```

## 権限

```
メール	店舗ID	役割	有効
```

## 設定

```
キー	値	備考
```

## 同期ログ

```
記録日時	種類	対象	範囲	結果	メッセージ
```

---

## 既存の店舗マスタ＋従業員マスタを1枚にまとめる

スプレッドシートを開き、メニュー **シフト基盤 → マスターデータに統合（不要シート削除）** を実行してください。
